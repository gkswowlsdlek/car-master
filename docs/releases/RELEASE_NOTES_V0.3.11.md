# Car-Master v0.3.11 — Dealer Experience / Meeting Ready

v0.3.11은 새로운 기능을 추가하는 버전이 아니라, 딜러가 미팅에서 핵심 업무 흐름을 빠르게 이해하고 직접 시연할 수 있도록 화면의 우선순위와 모바일 완성도를 다듬은 Preview입니다.

## Dealer Experience UX Revision

- 거래관리는 채팅이 아닌 거래 상태, 시공 일정, 금액과 다음 행동에 집중하도록 분리했습니다.
- Messenger는 Inbox와 거래정보를 작게, 대화 영역을 넓게 구성하고 메시지만 내부 스크롤되도록 정리했습니다.
- 알림 켜기·끄기, 전화, 거래정보, 더보기와 거래방 숨기기를 실제 동작에 연결했습니다.
- 거래정보 패널은 현재 상태, 다음 일정, 차량, 시공 품목, 상대 업체, 금액과 결제 상태만 빠르게 확인하도록 줄였습니다.
- 마이페이지에서 전화번호가 자동으로 읽기 좋은 형식으로 표시되며 이메일 검증, 활동지역 선택과 알림 토글을 제공합니다.
- 실제 회원의 기본 정보는 기존 Supabase 회원 테이블에 저장하고, 이메일 변경은 Supabase Auth 인증 흐름을 사용합니다.
- 알림 설정은 별도 DB Migration 없이 기존 브라우저 프로필 저장소에 유지됩니다.
- 시공 요청의 지역은 시도·시군구로 선택하고, 입고예정일은 기본 날짜 선택기를 사용합니다.
- 데모 시공점은 행정청 좌표와 겹치지 않도록 같은 생활권 안에서 분산 표시됩니다.

## 사용자 관점에서 달라진 점

- 딜러 홈에서 오늘 처리할 업무, 시공 예약, 읽지 않은 메시지를 먼저 확인할 수 있습니다.
- 새 시공 요청 진입점의 중복을 줄이고 가격 확인과 시공점 찾기 동선을 명확하게 정리했습니다.
- 시공 요청을 작성하다 다른 화면으로 이동해도 같은 탭에서는 작성 내용이 유지됩니다.
- 요청이 정상적으로 생성되면 임시 저장 내용이 제거되어 다음 요청에 이전 정보가 남지 않습니다.
- 네이버 지도를 불러오지 못하더라도 시공점 목록에서 비교와 선택을 계속할 수 있습니다.
- 모바일 거래방에서 가로로 잘리거나 상세 패널이 화면을 벗어나는 문제를 보완했습니다.
- 고객에게 의미 없는 내부 딜러 ID가 업무 화면에 직접 노출되지 않도록 정리했습니다.
- 랜딩 페이지의 핵심 문구를 가격 확인부터 시공 완료까지의 실제 업무 흐름에 맞춰 간결하게 개선했습니다.

## 유지된 기반

- Supabase 거래, 거래방, 채팅, 첨부파일 및 Realtime 연결
- 역할별 거래 접근 권한과 RPC 기반 상태 변경
- 네이버 지도 인증 실패 감지 및 목록 fallback
- `견적 → 시공예약 → 입고 → 작업완료` 상태 순서
- v0.3.10 Messenger의 데이터 분리와 모바일 전체 화면 구조
